# السرعة والأخطاء · دليل مالك TABO BOOKS

افتح `https://tabobooks.com/admin` وسجّل الدخول، ثم اختر **السرعة والأخطاء**.

## PageSpeed Insights

اضغط **فحص الموبايل** أو **فحص الكمبيوتر** بجوار الصفحة المطلوبة. ستفتح أداة Google الرسمية وتبدأ التحليل. الفحص خارجي عند الطلب؛ المتجر لا يحفظ نتائج أو يشغل فحوصًا دورية.

ابدأ بالموبايل. درجة الأداء 90–100 جيدة، 50–89 تحتاج تحسينًا، وأقل من 50 ضعيفة. راجع LCP وINP وCLS وتوصيات التقرير، وقارن نفس الصفحة والجهاز بعد أي تعديل. بيانات الاستخدام الفعلي قد تغيب إذا لم تتوفر عينات كافية. نتائج المختبر تتغير بين الفحوص؛ لا تعني درجة واحدة ضمانًا لتجربة كل عميل. لا تفحص روابط الطلبات أو التحميل الخاصة.

## Sentry

الربط اختياري ومتوقف افتراضيًا. يحتاج مشروع JavaScript في حساب المالك، وClient DSN عامًا من إعدادات المشروع، ثم الإعدادات التالية في خدمة Render الحالية:

```text
TABO_SENTRY_ENABLED=1
SENTRY_DSN=<public client DSN from Sentry>
TABO_SENTRY_PROJECT_URL=https://your-org.sentry.io/issues/?project=123456
```

لا تستخدم رمز إدارة أو API token مكان DSN. الكود يقبل نطاقات Sentry الرسمية المحددة فقط، ويعمل على نطاق المتجر الإنتاجي. لا يحتاج مخطط قاعدة بيانات أو تعديل بوابات الدفع. للتعطيل اجعل `TABO_SENTRY_ENABLED=0` وأعد النشر.

بعد التفعيل افتح **Sentry → Issues** واختر `production`. راجع تكرار الخطأ والصفحة والملف ورقم السطر، وشارك رابط المشكلة عند طلب إصلاحها. حالة «مفعّل» في لوحة المتجر تعني أن الإعداد المحلي صالح؛ تأكد من استقبال الأحداث داخل Sentry. لا يوجد ادعاء بفحص أحداث حقيقية قبل ربط الحساب واختبار وصول حدث.

الربط يرصد أخطاء JavaScript غير المعالجة وأكوادًا محددة لأعطال تحميل الأسعار وطلب الدفع ونقل الملف. لا يراقب أخطاء Python في الخادم، ولا يؤكد نجاح الدفع. تُحذف الرسالة الخام وبيانات المشتري والطلبات وروابطها الخاصة، وتُحفظ فقط معلومات فنية محدودة مثل النوع والموضع. تسجيل الجلسات والتتبعات والكوكيز وفتات التنقل وبيانات الطلبات متوقفة. قد يمنع حظر التتبع أو الشبكة وصول بعض الأحداث. فشل Sentry لا يعطل الشراء أو التحميل.

SDK المتصفح مثبت على 11.10.0 مع SRI وnonce وسياسة اتصال محصورة بنطاق استقبال المشروع. لا تُرسل أحداث من لوحة المالك أو بيئات المعاينة.
